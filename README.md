Menedżer Wydatków

Aplikacja terminalowa w Pythonie do zarządzania budżetem i wydatkami. 
Pozwala śledzić wydatki, kategoryzować je, przeglądać statystyki i filtrować dane.

Funkcje:
- Dodawanie, edytowanie i usuwanie wydatków
- Podział na miesiące i kategorie
- Statystyki: najdroższy miesiąc, średnia miesięczna, najczęstsze kategorie
- Filtrowanie po kwocie, kategorii i miesiącu
- Zapis danych w SQLite

Tech stack: Python, SQLite, OOP
